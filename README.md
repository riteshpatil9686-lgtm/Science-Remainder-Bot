## Quick Start (Free Google Version — Recommended)

1. Go to https://script.google.com → New Project
2. Copy contents of `google_apps_script_full.js`
3. Change `YOUR-MOMS-EMAIL@gmail.com` to the recipient's email
4. Click Save → Click Play (authorize)
5. Add trigger: Clock icon ⏰ → Day timer → 6:00 PM → Save
6. Done! Works even when laptop is off
